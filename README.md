# Smart Boxing Glove

## Overview

Smart Boxing Glove is a Final Year Project developed during the Bachelor's Degree in Electronics, Telecommunications and Computer Engineering at ISEL.

The project consists of an ESP32-based smart boxing glove capable of measuring punch force, speed and trajectory using inertial and piezoelectric sensors. The collected data is transmitted via Bluetooth Low Energy (BLE) for real-time monitoring and analysis.

## Features

- Punch force measurement
- Punch speed estimation (to do)
- Punch trajectory tracking
- Bluetooth Low Energy communication
- Rechargeable battery-powered system

## Technologies

- ESP32-C3
- ESP-IDF
- C
- Bluetooth Low Energy
- ADC
- I²C
- IMU
